# Scalar Space

**Math you can see.** Free, open source math lessons with equations, plain-language explanations, and interactive graphs.

🌐 **Live site:** https://xuunh.github.io/ScalarSpace/

## What's inside

Each topic has:

- **The equation**, written out clearly
- **Plain-words explanation** and a table of what each symbol means
- **Interactive graph** — drag sliders and watch the graph and equation change
- **Worked example** — revealed one step at a time
- **Practice problem** with a hidden answer

### Topics so far

| Algebra 1 | Algebra 2 |
|---|---|
| Slope-Intercept Form | The Quadratic Formula and Discriminant |
| Systems of Linear Equations | Polynomials from Their Roots |
| Absolute Value Functions | Logarithms as Undoing Exponents |
| Quadratics in Vertex Form | Square Root Functions |
| Exponential Growth and Decay | Rational Functions and Asymptotes |

## For teachers and tutors

- Every topic has its own link — hit **Copy link for students** and send it.
- **Teaching mode** (the corner-arrows button) hides the menu and makes everything bigger for screen sharing.
- Ask students to predict what a slider will do *before* they drag it.

## How it works

- Every topic is one file in [`data/`](data/). The list of topics is [`data/catalog.json`](data/catalog.json).
- The website (`index.html` + [`assets/`](assets/)) reads those files. No build step.
- GitHub Pages hosts it for free. Push a change → site updates in about a minute.
