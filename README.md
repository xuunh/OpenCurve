# OpenCurve

A visual tour of math, from Pre-Algebra to Topology.

**Live site:** https://xuunh.github.io/OpenCurve/

Scroll through 19 subjects, each shown as a glowing 3D model drawn from real math (the number line as a spiral, conic sections, the Lorenz system, a Möbius strip, and more). Built for students, tutors, and teachers, on laptops, Chromebooks, and classroom projectors.

## Subjects

Pre-Algebra · Algebra 1 · Geometry · Algebra 2 · Trigonometry · Pre-Calculus · Statistics · Probability · Calculus 1 · Calculus 2 · Linear Algebra · Calculus 3 · Differential Equations · Discrete Math · Number Theory · Real Analysis · Abstract Algebra · Complex Analysis · Topology

Topics for each course are coming soon.

## Run it locally

It's one file. Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server
```
